Privacy and reviewer preparation

Review App Store Privacy and Google Play Data safety before submitting: disclose crash data, other diagnostic data, and native installation/device identifiers collected for app functionality. Use conservative identity linkage for native diagnostics; no advertising or tracking. The React Native bridge and native SDK can attach an installation identifier even with default PII disabled. JavaScript reports remove user and context fields, but this does not establish removal of all native device identifiers. Sentry receives privacy-filtered error reports; application reports exclude audio, transcripts, translations, clipboard contents, API keys, and raw provider responses. Native reports can contain OS and device technical information. The existing provider-processing disclosures continue to apply.

Reviewer instructions must use Transcribe, Translate, Saved translations, and History terminology. Confirm a working restricted OpenRouter reviewer credential privately; do not place credentials in this file or Git.

Website documentation was reviewed: setup and support already describe the Auto-detect fix; privacy already describes Sentry error reporting. The version-only change needs no additional website behavior documentation.
